# אתר הטיול ליוון — GitHub Pages

האתר מוכן לפרסום כאתר סטטי.

## פרסום מהיר ב-GitHub Pages
1. יוצרים Repository חדש ב-GitHub, למשל `greece-2026`.
2. מעלים לשורש ה-Repository את הקבצים: `index.html`, `styles.css`, `app.js`.
3. נכנסים ל-Settings → Pages.
4. תחת Build and deployment בוחרים Deploy from a branch.
5. בוחרים `main` ו-`/(root)` ושומרים.
6. כתובת האתר תהיה בדרך כלל:
   `https://USERNAME.github.io/greece-2026/`

## תוכן האתר
- מפה כללית אינטראקטיבית.
- מפה נפרדת לכל יום עם קו המחבר בין התחנות.
- הסברים, זמני ביקור ועלויות משוערות.
- קישורי Google Maps ו-Waze.
- מלונות, המלצות ערב ותקציב יומי לארבעה.
- תצוגה מותאמת לטלפון ולמחשב.

## הערה
האתר משתמש ב-Leaflet ובמפות OpenStreetMap דרך CDN, ולכן נדרש חיבור אינטרנט להצגת המפות.
